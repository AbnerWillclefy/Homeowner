# BottomBar

Phone navigation (< `bp-tablet`): four fixed tabs at the bottom.

- Overview · Transactions · Planning · More. "Planning" opens a screen with Goals, Net worth, Projection and Accounts; "More" holds Bills to pay, Card bills, Categories and Settings.
- 20px icon + `11px` label. Active in `brand`. Touch target ≥ 48px.
- Respects `env(safe-area-inset-bottom)`.
