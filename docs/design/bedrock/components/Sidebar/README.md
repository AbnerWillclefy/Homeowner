# Sidebar

Desktop navigation: the brand on top, two groups, Settings at the bottom.

- ≥ `bp-wide` (1280px): full, `sidebar-width`. Between `bp-desktop` and `bp-wide`: icons only, `sidebar-collapsed`, with a tooltip on hover. Below `bp-desktop`: it disappears and becomes a top bar with a menu.
- Active item: `brand-soft` + `brand`, with `aria-current="page"`. A 16px lucide icon + label.
- Groups in `overline`: MAIN and PLANNING.
- Items only for screens that exist. A future feature gets no "coming soon" item.
