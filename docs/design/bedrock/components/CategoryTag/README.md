# CategoryTag

A spending category: an icon in a square in the category's colour, the name and its share.

- Icon colour `cat-<category>` on `cat-<category>-soft`. The category has the same colour in every chart, row and filter of the app.
- Sizes: 32px in lists, 24px in legends and chips.
- The share ("41%") in a neutral pill to the right of the name.
- Fixed icons per category (lucide): Housing `house`, Groceries `shopping-cart`, Eating out `utensils`, Transport `car`, Household bills `zap`, Subscriptions `repeat`, Health `heart-pulse`, Education `graduation-cap`, Leisure `ticket`, Shopping `shopping-bag`, Pets `paw-print`, Taxes and fees `landmark`, Other `circle-ellipsis`.
