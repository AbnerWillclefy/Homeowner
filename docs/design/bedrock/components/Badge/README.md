# Badge

Short state: status, delta or count. Always with a word or icon, never colour alone.

- `positive`: Paid, under pace, +3%. `warning`: Due in 2 days, over pace. `danger`: Late, over limit. `neutral`: Scheduled, Edited. `brand`: New, Selected.
- A 24px pill, `label`. An optional 12px icon before the text.
- `solid` only for the value marker on a chart ("R$ 200 under").

Implementation: shadcn/ui `Badge` with these variants.
