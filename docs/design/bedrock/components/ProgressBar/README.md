# ProgressBar

How much of a target is reached: a goal, a category limit, a reserve.

- Track `surface-sunken`, fill `brand`. Near the limit (≥ 85%) it turns `warning`; past it, `danger`, and the text says by how much.
- Below: the current amount in `text` on the left, the target and due date in `text-muted` on the right.
- 8px tall, full radius.
