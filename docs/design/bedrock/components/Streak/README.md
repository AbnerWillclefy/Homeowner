# Streak

The Resident's run of days in a button: a flame and a number. **Home** layer.

- **When to use**: in Today's header and on a Resident's page. Tapping opens the streak `Sheet` with the rules.
- Flame in `warning`. On a drained day the streak pauses: the icon becomes `pause` in `text-muted`, and the number stays.
- Zero is just a number, with no scolding tone.
- Accessibility: accessible name "Sequência: 6 dias" or "Sequência pausada: 6 dias".

The consumer provides the days and whether it is paused.
