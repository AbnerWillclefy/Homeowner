Epic 7: Finances redesign

Finances splits into three views that each answer one question: Resumo (how is the month going?), Gastos (where did the money go?) and Contas (what is still to pay?). Ajustes leaves the tabs. Charts are neutral ink with a hatch and always carry the amounts as text; teal stays for actions. Drawn in pt-BR with sample data at 390px; every number comes from data the API already returns. Copy is illustrative; the i18n catalogs own the real wording.
