# Only broken commitments break a Streak

A Streak breaks only when a Resident leaves a Committed Task undone. Ignoring or refusing a proposed Task, or having a day with nothing to do, pauses the Streak instead. The system is an advisor: it proposes and the Resident commits, so punishing people for proposals they never accepted would make them distrust the Day Plan. Growth still requires at least one Completion, so refusing everything never builds a Streak.
