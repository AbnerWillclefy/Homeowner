# Chores come due in flexible windows, not on fixed dates

A Chore repeats every N days, and the system chooses which day inside that window to make a Task of it, based on the Residents' Energy. A fixed due date would leave the system able to change only who does the work, never when, which defeats balancing Effort against Energy across days. A Chore can be narrowed to specific weekdays (for example, trash goes out on collection days) when the real world demands it, but flexibility is the default.
